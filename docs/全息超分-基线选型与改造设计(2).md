# 全息强度图超分：改造起点选型与网络设计

> 2026-10-10（v2，已按查证结果修正）
> 场景：数字全息重建**强度图** LR×4 → HR
> 目标：挑一个现成 SR 网络当起点，改造成全息专用网络，**效果超过其它对比模型**
> 配套：`~/桌面/数字全息超分-实验管线速览.md`（怎么跑）、`~/桌面/xuexi/数字全息超分辨率-方案与论文基线.md`（文献与设计论证）

## 0. 结论

**⚠️ v1 的建议已修正。** SwinIR 在全息领域**已经被用过多次**，其中一篇（Opt. Express 2025 基准研究）
跟你的任务正面重叠。所以：

| 角色 | 结论 |
|---|---|
| SwinIR 当**对照模型** | ✅ **必须做**，H2HSR 和基准研究都用了它，你不比说不过去 |
| SwinIR 当**方法骨架** | ⚠️ **有增量风险**，见第 2、6 节。要做可以，但改造必须够深 |
| **推荐起点** | ⭐ **Restormer**（全息领域检索不到应用，novelty 最干净）或 **NAFNet**（最快出数字） |

**无论从哪个起点出发，核心创新都是同一个**：把"窗口/通道"这对轴换成
**"条纹物理尺度 × 频带/孔径结构"**，并加物理一致性损失。

## 2. ⚠️ SwinIR 在全息领域已经被用过了（查证结果）

| 工作 | 怎么用的 |
|---|---|
| **H2HSR** · IEEE Access 12:90900, 2024 | 全息图→全息图 SR，比了 RDN / SwinIR / HAT，只改了第一层通道数（6 通道振幅+相位） |
| **基准研究** · Opt. Express 33(18):38696, 2025 | **全息强度图 + 相位，×2/3/4**，比 RCAN / SwinIR / 条件扩散。**与你的任务正面重叠** |
| **HoloPASWIN** · arXiv:2603.04926 | U 形 Swin + Swin-Tiny 主干 + 物理感知损失，同轴全息重建 |
| **STU-Net** · Opt. Eng. 63(11):111812, 2024 | Swin U-Net，无透镜全息细胞分割（非 SR） |
| Swin-ResUnet · Opt. & Laser Tech. 168:109952, 2024 | 闭合条纹相位符号反转校正 |
| Swin 散斑去噪 · Opt. & Lasers in Engineering, 2025 | 全息图散斑去噪 |

### 结论

我查到的**所有用法都是"原样用"**（最多改输入通道数），
**没有一篇动过它的窗口机制**，更没有把窗口尺寸与全息条纹的物理周期挂钩。

> 所以判断标准不是"用没用 SwinIR"，而是：
> 你的改造是**领域物理驱动**的（条纹周期是物理量 → 窗口不能写死 8×8），
> 还是**调参驱动**的（我试了几种窗口尺寸哪个好）。前者是贡献，后者是增量。

### 一个反直觉的发现（对你有利，值得写进引言）

H2HSR 的结果：**通用图像 SR 上 HAT > SwinIR，但在全息 SR 上 SwinIR > HAT**（32.85 vs 32.65）。

→ 这直接证明**自然图 SR 的架构排序不能迁移到全息域**，是你论文最好的开篇论点。

### 但也要知道对手的证据

HoloPASWIN **自己的消融表里 U-Net 打赢了它的 Swin**（相位 PSNR 53.91 vs 46.55），
作者归因于 Transformer 缺卷积的局部先验、且数据饥饿。这个域数据量比自然图 SR 少 1~2 个数量级。
**你从任何一个 Transformer 起点出发，都必须正面回应这条。**

## 4. ⭐ 首选起点：Restormer → HoloRestormer

### 4.1 为什么是它

1. **novelty 干净**：我检索不到任何全息/全息 SR/DHM 应用 Restormer 的工作
2. **结构天然对位**：它的核心模块 `Attention`(MDTA) **本来就是在通道维做注意力**
   —— 在自然图上"通道"是语义特征，在全息里**有用的"通道"就是频带**。
   把它换成频带注意力，几乎是原地替换，改动小、故事顺
3. **模块化干净**：`TransformerBlock` = `Attention` + `FeedForward`，两个模块各自独立，好插好消融
4. **轻量可调**：调 `dim` / `num_blocks` 就能压到很小，训练速度可控

### 4.2 原结构（`basicsr/models/archs/restormer_arch.py`）

```
Restormer = 4 级 U-Net
  每级: OverlapPatchEmbed → TransformerBlock × N → Downsample
                               TransformerBlock = norm1 → Attention(MDTA) → 残差
                                                + norm2 → FeedForward(GDFN) → 残差
  Attention(MDTA)   : 通道维注意力（C×C 转置注意力），带 depthwise conv
  FeedForward(GDFN) : 门控深度卷积 FFN
  底部: 再用 TransformerBlock，然后 Upsample 逐级回上去
```

关键类：`Restormer` / `TransformerBlock` / `Attention`(MDTA) / `FeedForward`(GDFN) /
`OverlapPatchEmbed` / `Downsample` / `Upsample`

### 4.3 三个改造点

#### 改造点 1：MDTA 的通道注意力 → 频带注意力（核心）

MDTA 现在在 `C` 个特征通道上算 C×C 注意力。改成在 `n_bands` 个频带上算：

```python
class BandAttention(nn.Module):
    """把 MDTA 的'通道轴'换成'频带轴'"""
    def __init__(self, dim, n_bands=6, num_heads=4):
        super().__init__()
        self.n_bands = n_bands
        self.temperature = nn.Parameter(torch.ones(num_heads, 1, 1))
        self.qkv = nn.Conv2d(dim, dim * 3, 1)
        self.proj = nn.Conv2d(dim, dim, 1)

    def forward(self, x):
        B, C, H, W = x.shape
        F = torch.fft.rfft2(x, norm='ortho')                 # (B,C,H,W//2+1) 复数
        bands, idx = self.split_radial(F, H, W, self.n_bands) # 按半径分环 -> n_bands 个复数子带
        # 每个子带 -> token，在 n_bands 个 token 上做注意力（极便宜）
        qkv = self.qkv(torch.cat([torch.stack([b.real for b in bands], 2),
                                  torch.stack([b.imag for b in bands], 2)], 1))
        # ↑ 让低频带指导高频带的幅度/相位 —— 这就是"带外延拓"的可学习形式
        out = self.attention(qkv)                             # 复用 MDTA 的转置注意力写法
        out = self.merge_bands(out, idx, H, W)
        out = torch.fft.irfft2(out, s=(H, W), norm='ortho')
        return self.proj(out)
```

- `split_radial` 也可以换成**按方向分扇区**（对应孔径/NA 结构）
- 注意力只在 `n_bands`（4~8）个 token 上做，**开销可忽略**（这是你同时主张效果和效率的底气）

**文献支撑**：SEMNet 的极坐标傅里叶子带 MoE、HoloMamba 的 NA-aware band fusion、
HoloSSL 的 frequency-aware 分支，三条独立工作都指向"全息里有用的维度是频带"。

#### 改造点 2：GDFN 的卷积核改成方向性

`FeedForward`(GDFN) 里是 3×3 depthwise conv。全息条纹有明确方向，
改成**沿条纹方向的可分离卷积**（1×k 与 k×1 并联，或按估计的条纹角旋转采样核）。

#### 改造点 3：双分支 + 双向门控

在 `TransformerBlock` 里，把 `Attention` 换成分支后，并联一个空域窗口分支
（可以用原 SwinIR 的窗口注意力，或就用 dwconv），两者互相门控。

⚠️ **门控方向别记反**（DAT 原码 `dat_arch.py:422-435` 是 C-Map 调 attention、S-Map 调 conv）：

```python
attn_out = attn_out * torch.sigmoid(channel_map(freq_out))   # 频域提示哪些通道重要
freq_out = freq_out * torch.sigmoid(spatial_map(attn_out))   # 空域提示哪些位置重要
x = attn_out + freq_out
```

### 4.4 损失设计（比结构更决定成败）

| 项 | 形式 | 权重建议 |
|---|---|---|
| 主损失 | L1 / Charbonnier | 1.0 |
| **高频加权** | 对超出 LR 截止频率的频带加权 L1 | 0.1~0.5 |
| **物理一致性** | `‖ \|ASM(Ô)\|² − H_LR ‖₁`（有前向模型时） | 0.1 |
| 感知（可选） | LPIPS | 0.05 |

⭐ **物理一致性不是可选项**：HoloADMM 的对比显示，**唯一能从仿真迁移到真实数据的模型，
就是前向模型在环的那个**，其余"输出无意义的重建"。

## 5. 次选起点：NAFNet（最快出数字）

**用途**：当天跑通管线、拿到下界数字，别一上来就啃大模型。

- U-Net + SimpleGate + 简化通道注意力，**无自注意力，训练最快**
- 改造：`SimplifiedChannelAttention` → **频带门控**；U 形深层并联频域分支
- 好处：最轻最快，**主张效率时你自己就是最强对手**

## 6. 如果你坚持用 SwinIR 当骨架

不是不行，但要**改得够深**，否则审稿人的第一反应就是"你只是改了 SwinIR 的窗口"。
最低要求是**四个改造点全做**（不是只做窗口）：

```
conv_first → layers: 4 × BasicLayer
              每层 = RSTB × 6 + PatchMerging
              RSTB = resi_conv + (SwinTransformerBlock × 6) + conv
              WindowAttention = 固定 8×8 窗口 + 相对位置偏置
           → norm → conv_after_body + 残差 → Upsample(pixelshuffle) → conv_last
```
关键类：`SwinIR` / `RSTB` / `SwinTransformerBlock` / `WindowAttention`

1. **窗口尺寸跟随条纹周期**：`T = 1/|f_c|`（`f_c` 从 LR 图频谱峰估计），
   `window ≈ k·T`，各向异性（沿条纹方向拉长）。**先单独做这一个变量的消融**
2. **并联频域分支**（同第 4.3 节改造点 1 的 `BandAttention`）
3. **双向门控**把两个分支互相调制
4. **输入侧**：`in_chans=1`、删 RGB mean、**不用 ImageNet 预训练**、BN→LN/GN

> **不用 ImageNet 预训练**这条有实测依据：HoloPASWIN 发现 ImageNet 初始化**无收益**，
> 而 ResNet-18 预训练的 U-Net 反而更差——自然图先验会拖后腿。

## 7. 五个通用改造原则（不管选哪个起点都要做）

1. **双分支**：空域（条纹尺度）× 频域（带外延拓），互相门控 —— 整个方案的核心
2. **尺寸与物理挂钩**：窗口/卷积核尺寸由条纹周期决定，不是拍脑袋的超参
3. **输入侧**：1 通道、自适应归一化、无 ImageNet 预训练、BN→LN/GN
4. **损失**：L1 + 高频加权 + 物理一致性
5. **条件化**（做复值/相位时再加）：z / λ / Δ 通过 AdaLN/FiLM 注入每层
   —— 距离鲁棒性是文献里最一致的失败点（HoloPASWIN 在 z±1mm 掉到 10dB 以下）

---

## 8. 为什么这样改能赢对比模型

| 优势来源 | 说明 |
|---|---|
| **频率对齐** | RCAN/SwinIR/HAT 都在空域做，SR 缺的却是带外高频；你的频域分支直接在缺失发生处操作 |
| **物理尺度对齐** | 对比模型的窗口/卷积核尺寸与条纹周期无关，你的按周期自适应 |
| **可迁移性** | 物理一致性损失让 sim→real 能迁移，纯监督的对比模型在真实数据上会崩（HoloADMM 已证） |
| **不靠堆参数** | 带间注意力只在 4~8 个 token 上做，开销可忽略 → 可同时主张**效果**和**效率** |
| **叙事闭环** | 引言用"SwinIR>HAT 说明架构排序不可跨域迁移"，方法用"频带+条纹尺度"，对比表打赢两层基线 |

## 9. 落地顺序（按风险从低到高）

| 阶段 | 做什么 | 预计 |
|---|---|---|
| 1 | SRResNet + EDSR 跑通管线，确认数据/退化无误 | 1 天 |
| 2 | 加 RCAN、**SwinIR**、NAFNet 当对照，拿到完整基线表 | 3~5 天 |
| 3 | 起点选 Restormer，**先只做频带注意力**这一个改造 —— 最便宜的一次验证 | 3 天 |
| 4 | 加方向性卷积 + 双向门控 | 3~5 天 |
| 5 | 加物理一致性损失、高频加权 | 2 天 |
| 6 | 补 HAT / MambaIR 对照、3 种子、距离鲁棒性 | 5~7 天 |
| 7 | 再做复值/相位扩展（若走那条线） | — |

**阶段 3 是关键决策点**：如果只换频带注意力就有提升，"频带是有效维度"这个论点就站得住；
如果没有，先检查是不是 LR 太小、频带数设置不当，再决定要不要继续投入。

## 10. 注意事项与风险

1. **别照抄 DAT 的 AIM 门控方向**——原码是 C-Map 调 attention、S-Map 调 conv
   （`dat_arch.py:422-435`），写反了实验会莫名变差
2. **别用 ImageNet 预训练**（HoloPASWIN 实测无收益甚至有害）
3. **别只报 PSNR/SSIM**——散斑重，PSNR 会饱和且与视觉背离，必须配 LPIPS
4. **每个模型至少 3 个种子**报均值±标准差（本域数据少、方差大）
5. **通用对照模型必须自己重训**，不能抄论文数字
6. **纯强度图故事偏弱**：领域 SOTA（H2HSR / HSR-CFAT / HoloFormer）都在做复值场或相位。
   时间允许的话扩成强度 + 相位联合会显著增强分量
7. **窗口 vs 全局相干存在文献矛盾**：一派说窗口注意力破坏条纹全局相干（HoloMamba 作者），
   一派说窗口注意力正好抑制周期性 ghost/孪生像（HoloPASWIN）。**没有已发表对照消融** ——
   你的窗口消融实验正好能填这个空，这本身是个值得写的发现
8. **"检索不到应用"是负面结果**，不等于不存在。投稿前对 Restormer / NAFNet 再自查一遍
