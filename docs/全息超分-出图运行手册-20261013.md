## 3 逐样本指标落盘（Fig.2/3/6/8/9 的数字来源）

`export_per_sample_metrics.py` 自带 `--sr-template`，**必须指向真机布局**：

```bash
cd /root/autodl-tmp/holo_figures
python3 scripts/export_per_sample_metrics.py compute \
  --hr-dir /root/autodl-tmp/HR \
  --results-root /root/autodl-tmp/holo_project/experiments \
  --models HoloRestormer_mdta SwinIR \
  --seeds 10 \
  --sr-template  '{root}/{model}/results/test/{number}_SR.bmp' \
  --ref-template '{root}/{model}/results/test/metrics.json' \
  --test-list /root/autodl-tmp/holo_project/data/splits/test_meta.txt \
  --out data/per_sample_metrics_all.json
```

- `--seeds` **只写实际跑了的种子**。默认是 10/20/30，现在只有 10，不写会因"缺种子"报错退出。
- `--test-list` 必须用**测试集**清单（`test_meta.txt`），不是 val。
- 先跑 `--no-lpips` 试通管路可以，但**正式出图必须去掉**（协议 §12.1 第 6 条）。

> ⚠️ **必须加 `--no-check`**（2026-10-13 实测确认的接口差异，不是 bug）：
> `evaluate_holo.py` 的 PSNR/SSIM 算在**浮点** SR 上（`model(inp).clamp(0,1)`），
> 而 BMP 母版是 `np.clip(sr*255).astype(uint8)` 之后的 **8 bit 量化**结果。
> `export_per_sample_metrics.py` 从 BMP 复算再和 `metrics.json` 比，容差是 **1e-6**，
> 8 bit 量化带来的 PSNR 偏差约 **0.007 dB**，**必然超容差**。
>
> **口径定死**：论文里的数字用 `metrics.json`（浮点算出来的），出图用 BMP。
> 两者的差是 8 bit 量化的固有差，不是错误。所以出图链路加 `--no-check`。
