### 0.5 v7 内的六项放宽（相对早期草稿）

早期草稿把若干"最佳实践"写成了硬约束，实际超出 SCI 投稿所需，且显著推高机时。v7 统一放宽如下
——**放宽的是仪式，收紧的是诚信**：

| # | 早期草稿 | v7 冻结值 | 理由 |
|---|---|---|---|
| 1 | 全部模型 × 3 种子（21 runs ≈ 16 天） | **核心对比集**（本方法 + 最强基线）× 3 种子，**外围基线** × 1 种子（≈ 8.5 天） | 省 2/3 机时；论文注明哪些是单种子即可 |
| 2 | 禁止 BatchNorm（会挡住 DAT） | **允许 BatchNorm**；OOM 降级顺序改为"先开 gradient checkpointing；仍 OOM 才降 micro=1，此时该模型须 BN→GN" | 原规则与"对照模型原封不动跑"互斥，是死结 |
| 3 | 显著性检验（Wilcoxon+Holm+效应量）强制 | **推荐但非必需**（`statistical_test=optional`） | 光学期刊通常只要求 mean±std；工具保留在出图规范 §J |
| 4 | `meta` 退化参数接口启用 | **v7 暂不启用**（`meta_interface_enabled=false`） | 只有本方法会用 → 额外输入 → 公平性争议，不值得 |
| 5 | 聚合交叉校验容差 1e-9 | **1e-6** | 浮点累加顺序差异即可达 1e-12~1e-9，1e-9 会误报 |
| 6 | 验证频率 2500（24 个点） | **5000**（12 个点） | 每 run 省约 1.4 h，并少存一半 checkpoint |

**未放宽（诚信底线，动一条整表作废）**：固定划分与测试集退化、**只用 val 选 checkpoint**、
不用预训练权重、每个 run 记 config 哈希、禁止部分重跑。

```ini

train_speckle_contrast=0.30,0.80
train_speckle_corr=3.0,6.0
train_poisson_gain=800,4000
train_read_std=0.003,0.010

# 验证集：固定值
val_diffraction_cutoff=1.0
val_aa_sigma=0.50
val_speckle_contrast=0.60
val_speckle_corr=4.0
val_poisson_gain=2000
val_read_std=0.005

# 测试集：与验证集完全相同
test_diffraction_cutoff=1.0
test_aa_sigma=0.50
test_speckle_contrast=0.60
test_speckle_corr=4.0
test_poisson_gain=2000
test_read_std=0.005
```

### 4.1 退化链（顺序不可变）

```
HR → ① 圆形孔径衍射低通  cutoff = diffraction_cutoff/(2·scale)  [cycles/px, HR 网格]
   → ② 抗混叠高斯低通    σ = aa_sigma  [LR 像素]
   → ③ 面积平均降采样    ×4
   → ④ 乘性散斑          contrast, corr_px  [LR 尺度施加]
   → ⑤ 泊松散粒 + 高斯读出噪声
   → ⑥ 8 bit 量化 → LR
```

### 4.2 关键规范

1. **训练集随机、验证/测试固定**：训练时逐样本从区间内均匀抽样（提升泛化）；验证/测试用**单一固定值**，保证所有模型面对完全相同的退化。
   *（注：训练区间覆盖验证/测试取值。）*
2. **验证集与测试集的退化参数数值必须完全相同**（上表 val = test），使验证集上的模型选择逻辑与测试保持同一条件。
3. 退化种子按 `image_seed(文件名, scale)` 确定，保证可复现。
4. **测试集退化对所有模型绝对一致**——这是整份协议的地基。
5. `diffraction_cutoff` 的物理含义：成像系统截止频率。LR 的 Nyquist 位于 HR 网格的 `1/(2·scale)=0.125` cycles/px；`cutoff=1.0` 表示恰好等于 LR Nyquist。

### 7.1 `iteration` 的定义（关键，禁止歧义）

**1 iteration = 1 次 optimizer update**，不是 1 次 micro-batch 前向。
因此 `total_iterations=60000` 表示 60000 次参数更新，每次更新消耗 `2×4=8` 个样本，共 `480000` 个样本。

### 7.2 batch 规范

- **effective batch 固定为 8**，这是不可变约束。
- 默认 `micro_batch=2, accum=4`。
- **OOM 时的合法处理顺序（必须按序，不得跳步）**：
  1. **先打开 gradient checkpointing**（`use_checkpoint=true`），保持 `micro_batch=2`。
     Restormer / SwinIR / DAT / HAT 都支持；代价是慢一些，不影响数值结果。
  2. 仍 OOM 时才降到 `micro_batch=1, accum=8`。降级后 **effective batch 仍为 8**，
     但 BatchNorm 的批统计失效 → **该模型必须把 BatchNorm 换成 GroupNorm**。
  3. 降级必须记录进 `run_manifest.json`（字段 `oom_downgraded` / `oom_bn_to_gn`）。
- **禁止**通过减小 effective batch 来省显存。

### 7.3 AMP 规范

- 前向用 `torch.cuda.amp.autocast(dtype=torch.float16)`；`GradScaler` 只在 optimizer update 时 `step()` / `update()`。
- **损失计算必须在 float32 下进行**：所有损失项（含 FFT）先退出 autocast，再计算。
  原因：fp16 下 FFT 的精度不足以支撑频域损失。
- 损失在 backward 前**必须除以 `gradient_accumulation_steps`**（见 §9.5）。

### 7.4 权重 EMA（强制）

- 训练全程维护一份 EMA 权重，`decay=0.999`，并做 warmup 校正：
  `d = decay × (1 − exp(−step / ema_warmup_iters))`，`step` 从 1 开始。
- **验证与 checkpoint 选择一律使用 EMA 权重。**
- 训练脚本必须**同时记录 raw 权重的验证指标**写入日志（供事后审计），但不用于选点、不用于报数。
- 最终交付保存两份：`net_g_ema.pth`（正式）与 `net_g_raw.pth`（审计）。

### 7.5 数据增强

`use_hflip=false`、`use_rot=false`，**冻结**。

> 物理前提：退化算子的孔径为圆形、高斯核各向同性、散斑各向同性、降采样为面积平均 → 退化整体具有 D4 对称性；
> 协议规定"数据已包含旋转扩展"，故不额外增强。
> 若日后查明数据集**未**包含旋转扩展，属协议缺陷，须走 §0.3 的版本升级流程（不允许只改这一个字段）。

## §9 损失函数（固定，所有模型完全相同）

### 9.1 总损失

```
L_total = L_pixel + 0.1 · L_freq + 0.2 · L_hf
```

所有输入 SR、HR ∈ [0,1]^{B×3×H×W}，float32。`scale=4`。

### 9.2 `L_pixel`

```
L_pixel = mean( |SR − HR| )          # 逐元素 L1，reduction=mean
```

### 9.3 `L_freq` —— 引导频域损失（GFL）

记 `norm='ortho'` 的二维 FFT，并做 `fftshift` 到中心：

```
S = fftshift(fft2(SR, norm='ortho'))          # 复数
H = fftshift(fft2(HR, norm='ortho'))          # 复数
D = |S − H|                                   # 复数差的模，逐频率

f_LR = 1 / (2·scale) = 0.125  [cycles/px, HR 网格]
r̂(u,v) = sqrt(fy² + fx²) / f_LR               # fy,fx = fftshift(fftfreq(H)), fftshift(fftfreq(W))
                                              # r̂ = 1 恰好是 LR 的 Nyquist

ρ(t) = clamp(1 − t / 30000, 0, 1)             # t = 当前 optimizer 迭代数（1-based）
M(t) = 1[ r̂ ≥ ρ(t) ]                          # 布尔 mask
L_freq = Σ(D ⊙ M) / Σ(M)                      # 在 mask 上取均值
```

**语义**：训练早期（`t→0`）只监督**带外**（`r̂ ≥ 1`，即信息真正丢失、需要外推的区域）；
随训练推进 `ρ(t)` 降到 0，监督扩展到全频带。这与 DNN 的 Frequency Principle（先学低频、后学高频）互补，
避免模型在低频已经学好之后仍被低频误差主导。

**实现要求**：mask 必须在每次 optimizer iteration 重算（`ρ` 随 `t` 变）；mask 保证非空。

### 9.4 `L_hf` —— 带外高频加权 L1

```
σ_hp = 1 / (√2 · π · f_LR) = 1.8006  [px, HR 网格]      # 固定常数
x_hf = x − GaussianBlur(x, σ_hp)                        # 固定可分离高斯核，核宽 = 2·ceil(2σ)+1 = 9，padding=reflect
L_hf = mean( |SR_hf − HR_hf| )
```

**σ_hp 的来路**：高斯低通 `exp(−2π²σ²f²)` 的 1/e 截止位于 `f = 1/(√2πσ)`；
令该点正好落在物理带限 `f_LR = 0.125` 上，解得 `σ_hp = 1.8006 px`。
即：**被加权的高频区，起点就是物理上信息开始丢失的那个频率。**

SR 与 HR 必须使用**同一个**高斯核（同一 σ、同一核宽、同一 padding）。

### 9.5 与梯度累积的配合

```
loss = L_total / gradient_accumulation_steps      # 在 backward 前除
```

### 9.6 禁止

- **禁止**每个模型使用不同损失。损失是全局常量。
- **禁止**使用 Focal Frequency Loss（有 NaN 报告），本协议指定 GFL。
- **禁止**使用对抗损失 / 感知损失作为**训练**损失（LPIPS 只在最终评估时计算，见 §12）。
- **禁止**梯度裁剪（`gradient_clip_enabled=false`，`gradient_clip_norm=none`）。

### 12.2 D4 自集成（强制同时报告）

最终评估必须产出**两组**数字，且两组必须都写进报告：

| 组 | 名称 | 说明 |
|---|---|---|
| 1 | 方法名（如 `HoloRestormer`） | 单体前向 |
| 2 | 方法名 + `+`（如 `HoloRestormer+`） | D4 八变换自集成 |

自集成定义：对输入做 8 种 D4 变换（4 个旋转 × 2 个翻转）分别前向，逆变换回原坐标系后**取平均**。
施加到**所有**模型上，保证公平。

> **合法性依据**（来自 `holo_degrade.py`，可复核）：孔径 `circle`（各向同性）、高斯抗混叠核各向同性、
> 散斑为各向同性复高斯相关场、降采样为面积平均 → 整个退化算子 D4 不变。
> 因此翻转/旋转后的图像对，其退化**严格等效**，自集成不是启发式技巧。

单体数字进主表；`+` 数字作为单独一列。禁止只报 `+`。

## §16 网络接入规范（**唯一自由变量**）

### 16.1 允许不同的字段（仅此三个）

```ini
[network]
network_name=<字符串，用作实验目录名>
network_type=<BasicSR 注册的类名>
network_params=<单行合法 JSON>
```

**除这三个字段外，本文件其余任何字段都不得因模型而不同。**

### 16.2 接口契约

```python
class YourNet(nn.Module):
    def __init__(self, **network_params):      # network_params 必须可 JSON 序列化
        ...

    def forward(self,
                x: torch.Tensor,               # (B, 3, H, W) float32, 范围 [0,1]
                meta: torch.Tensor | None = None   # (B, 6) float32，列序见 §2.3；可忽略
                ) -> torch.Tensor:             # (B, 3, 4H, 4W) float32
        ...
```

1. **输入**：`(B, 3, H, W)`，float32，范围 `[0,1]`，**不做任何预归一化**（禁止减 ImageNet mean、禁止除 std）。
2. **输出**：`(B, 3, 4H, 4W)`，float32。评估前统一 clamp 到 `[0,1]`（§12.1）。
3. `scale` 固定为 4；输入 `H`、`W` 保证可被 4 整除（由数据保证）。
4. `meta` 是可选输入。**忽略或使用都合法，但必须在所有模型间保持一致的信息可达性**——
   即任何模型都可以用，不存在只有某个模型能看到 `meta` 的情况。
5. 必须是**全卷积或对 `(H,W)` 尺寸不敏感**：验证/测试是整图，尺寸不固定。
   窗口划分必须处理非整除尺寸（`padding` 兜底）。

### 16.3 强制要求

| # | 要求 |
|---|---|
| 1 | 必须基于 **BasicSR**，使用 `HoloPairedDataset`、`holo_protocol`、`holo_metrics` |
| 2 | **禁止使用任何预训练权重**（`pretrained_weights=false`） |
| 3 | **允许使用 BatchNorm**（DAT 等架构内部需要，不得为此改动对照模型）。但若因 OOM 降到 `micro_batch=1`，该模型必须把 BN 换成 GN（见 §7.2） |
| 4 | 训练`drop_path` 等随机正则允许（且自动用于全部模型，若该模型有此机制）；**eval 下必须全部关闭** |
| 5 | 前向必须确定性（eval 下不得有随机性） |
| 6 | 必须能报告**参数量**与**×4 输出 `3×512×512` 时的 FLOPs**，写入 `run_manifest.json` |
| 7 | 输出不得有额外的后处理（如自实现的锐化、直方图匹配） |
| 8 | 必须通过冒烟测试：随机输入 `(1,3,64,64)` → 输出 `(1,3,256,256)`，且 `torch.isfinite(out).all()` |
| 9 | 必须能通过 `torch.autograd` 反传（频域模块若用复数，注意实现方式） |

### 16.4 建议对照模型清单（最低必做集）

| 层次 | 模型 | 备注 |
|---|---|---|
| 管线验证 | **SRResNet** | 最轻，用来验数据/退化无误 |
| 通用 SR | **RCAN** | 域内基准研究用的就是它 |
| 通用 SR | **SwinIR** | 域内基准研究用过，**必比** |
| 轻量高效 | **NAFNet** | 最快，用来主张效率 |
| 通用 SOTA | **HAT** | 通用 SOTA 代表 |
| 通用 SOTA | **DAT** | 全息领域真空，作为对照有价值 |
| 本方法 | **HoloRestormer** | 主方法（可含多个消融变体） |

**机时估算（§14.3 的种子策略下）**：7 个模型里取 2 个作核心对比集跑 3 种子，
其余 5 个跑 1 种子 → `2×3 + 5×1 = 11` 次 run。
按 18.5 h/run ≈ **8.5 天**；若验证频率取 5000（§0.5-6），再省约 1 h/run。
（全部跑满 3 种子是 21 次 run ≈ 16 天，属加分项，非必需。）

### 16.5 消融变体的处理

本方法的消融变体（如去掉频域分支、去掉条件注入）**属于不同网络**，
各自占用独立的 `network_name`，跑满 **3 个种子 × 60000 iter**（消融变体属"核心对比集"，
不受 §14.3 的单种子放宽），其余配置完全相同。

> 消融变体**不允许**只跑 1 个种子或缩短迭代——它同样是网络，受同一套协议约束。

## §18 规则清单（完整，冻结）

1. 所有网络必须读取本文件。
2. 除 `network_name`、`network_type`、`network_params` 外**禁止修改任何字段**。
3. 已确定的 `network_params` 一经冻结不得因结果调整（§14.2）。
4. LR4 为预生成数据，**禁止训练时在线生成退化图**。
5. HR 与 LR4 文件名按数字一一对应。
6. 所有模型使用**相同的** train / val / test 清单。
7. 所有模型使用**相同的** 10 张 visual_samples 清单。
8. 训练旋转与镜像增强关闭（`use_hflip=false`、`use_rot=false`）。
9. 测试分别保存 LR、SR、HR 未压缩 BMP。
10. 最终结果报告测试集 PSNR、SSIM、LPIPS、RMSE、MAE。
11. 最终报告的核心对比集用种子 10、20、30 的**均值和标准差**；外围基线用种子 10 并**标注**。
12. Checkpoint **只**根据 val 的最高 PSNR 选择；并列时用 SSIM 破平；**禁止使用 test 选 checkpoint**。
13. PSNR/SSIM 使用 RGB、[0,1]、`crop_border=4`。
14. SSIM 固定 11×11、高斯 `sigma=1.5`、`data_range=1.0`、`channel_axis=2`、逐通道取均值。
15. LPIPS 固定 AlexNet、RGB `[-1,1]`、`crop_border=4`、`spatial=false`，并固定实现版本。
16. OOM 时**先开 gradient checkpointing**；仍 OOM 才 `micro 2×4 → 1×8`，且该模型须 BN→GN。**effective batch 恒为 8**；所有模型统一启用 AMP float16。
17. **iteration = 一次 optimizer update**，不是一次 micro-batch 前向。
18. LPIPS 必须校验 `lpips==0.1.4` 与 `alex.pth` SHA256；未通过校验**禁止**最终评估。
19. SSIM 必须使用 `scikit-image==0.19.3`。
20. 损失必须在 backward 前除以 `gradient_accumulation_steps`；`GradScaler` 只在 optimizer update 时 `step()/update()`。
21. Python / NumPy / PyTorch / CUDA / worker / data order 与 cuDNN 确定性开关**必须启动时校验**。
22. val 与 test 共用 `holo_metrics` 的**同一实现、同一参数**。
23. 全息实验统一 `use_hflip=false`。
24. 所有网络统一**关闭梯度裁剪**。
25. val/test 固定 `batch=1`、整图、无 resize、无 padding、保持原生尺寸；**尺寸不符直接报错**。
26. DataLoader 固定 `pin_memory=false`、`persistent_workers=false`、`prefetch_mode=null`；val/test `num_workers=0`。
27. val 只计算 PSNR、SSIM、RMSE、MAE，**不计算 LPIPS**；LPIPS 仅用于最终 test 报告。
28. 接入新网络必须统一使用 basicsr、`HoloPairedDataset`、`holo_protocol`、`holo_metrics`，以及相同的数据划分、训练参数、AMP、梯度累积、EMA 与评估协议；**唯一变量是网络结构**。
29. `nvidia_driver_version` 仅作运行环境记录；`validate_nvidia_driver=false`，不因驱动版本阻断实验。
30. 训练期间及每次验证**禁止保存验证图片**。
31. 所有对比实验完成后，每个模型使用其**按 val PSNR 选出的最佳 checkpoint**，仅对固定 visual_samples 的 10 张 test 样本做一次视觉导出。
32. 视觉导出只保存未压缩 BMP 的 LR/SR/HR，**不计算或汇报测试指标**。
33. 损失固定为 `L_total = L1 + 0.1·GFL + 0.2·HF`，定义见 §9，**所有模型完全相同**。
34. 训练**必须**启用权重 EMA（decay 0.999 + warmup 校正），验证与选点使用 EMA 权重。
35. 总迭代固定 **60000**；milestones 固定 `30000,48000,54000,57000`；warmup 固定 2000。
36. **必须**同时报告单体与 D4 自集成两组数字；自集成施加到所有模型。
37. 数据集必须提供逐样本退化参数表（供出图图注与诊断）；**v7 不把 `meta` 喂给网络**（§2.3）。
38. 模型输出评估前**必须** clamp 到 `[0,1]`。
39. **禁止任何预训练权重**；允许 BatchNorm（但 `micro_batch=1` 时必须换成 GN，见规则 16）。
40. 每个 run 必须产出 `run_manifest.json`，含配置哈希与代码 commit。
41. **禁止部分重跑**：任何协议变更必须全部实验重跑。
42. 训练日志中若出现学习率全程恒定，该 run **无效**，必须重跑。
43. 论文图件必须**全部由脚本生成**，禁止手工 PS、手工拼图、手工抄写指标数字。
44. 论文正文图统一取 **seed 10**；曲线与表格核心对比集用 3 种子均值 ± 标准差，外围基线用单种子并标注。
45. 所有图件的 **colorbar / 显示范围必须全局统一**；LR 面板必须 bicubic 上采样；禁止 JPEG。
    数据面板必须脚本生成；排版微调允许但须记录。
46. **Fig. 4（频谱 + 物理截止线）与 Fig. 5（验证曲线 + LR milestone 竖线）为必需图**，缺失即视为实验不完整。
47. 评估脚本必须落盘 **`per_sample_metrics.json`**（逐样本 5 项指标）与 **`roi.json`**（冻结的 ROI 坐标）；
    未落盘则 Fig. 2 / Fig. 3 无法合规产出。
48. 论文出图规范见配套文件《全息超分-论文出图规范-v7.md》，与协议同等冻结。
49. `per_sample_metrics.json` 与 `roi.json` 的 **schema 按出图规范 §I 冻结**；
    键必须为字符串；输出必须 `sort_keys=True`；落盘时必须自检（样本集一致、3 种子齐全、有限值）；
    且**逐样本聚合出的均值必须与 `test_metrics.json` 的聚合值一致（容差 1e-9）**。
50. `roi.json` **必须写明坐标系约定**（网格 / 格式 / 原点 / 开闭），ROI 尺寸全局统一，
    坐标**由算法生成、禁止人工框选**，生成后冻结。
51. **配对显著性检验为推荐项而非必需**（`statistical_test=optional`）。若报，按出图规范 §J 的
    冻结方案执行：Wilcoxon signed-rank（双侧）、逐图配对、3 个种子的 p 值全报、
    Holm–Bonferroni 校正、并报效应量（median ΔPSNR + 95% bootstrap CI，固定随机种子）。
52. **主表必须由脚本直接生成 LaTeX / Typst 片段**（csv/tex/typ/md 同源），
    最优/次优加粗下划线由脚本自动判定；**禁止手工排表、禁止手抄数字**。

## §20 禁止事项总表

| # | 禁止 | 原因 |
|---|---|---|
| 1 | 部分实验使用不同协议 | 整表作废 |
| 2 | 用测试集选 checkpoint / 调超参 | 数据泄漏，学术不端 |
| 3 | 因结果不好回头调某个模型的超参 | 选择性调参 |
| 4 | 只跑 1 个种子 / 缩短迭代 | 违背 §14 公平性 |
| 5 | 使用预训练权重（含 ImageNet） | 文献实测本域无收益甚至有害 |
| 6 | 降到 `micro_batch=1` 却不把 BatchNorm 换成 GN | BN 批统计在 batch=1 时失效 |
| 7 | 训练时在线生成 LR | LR 必须全局一致 |
| 8 | 使用 Focal Frequency Loss | 有 NaN 报告 |
| 9 | 梯度裁剪 | 改变优化轨迹，破坏可比性 |
| 10 | 训练期间保存验证图片 | 磁盘与时间浪费 |
| 11 | 只报 PSNR/SSIM，不报 LPIPS | 本域散斑重，PSNR 会饱和且与视觉背离 |
| 12 | 只报自集成（`+`）数字 | 必须同时给单体数字 |
| 13 | 改动 `rng` 调用顺序生成退化参数表 | LR 图像会变，全部实验作废 |
| 14 | 在配置文件里写死绝对路径 | 换机器即失败 |
| 15 | 手工 PS / 手工拼图 / 手抄图上的指标数字 | 不可复现，且易抄错 |
| 16 | 误差图或频谱图逐格自适应 colorbar | 会掩盖方法间差异，误导审稿人 |
| 17 | LR 面板用最近邻上采样 | 显得输入过差，不公平呈现 |
| 18 | 用本方法的结果挑选展示样本 | 选择性报告，学术不端风险 |
| 19 | 只展示成功案例 | 缺少局限分析，扣分 |
| 20 | 图件存为 JPEG | 压缩伪影污染细节对比 |
