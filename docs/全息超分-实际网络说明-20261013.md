class HoloRestormerV3(nn.Module):   # 研究版：8 个开关【默认全开】

## 2 基线版 `HoloRestormer` 与官方 Restormer 的确切差异

**相同**（逐项核对过源码）：
- `HoloStem(use_homomorphic=False)` → 返回 `OverlapPatchEmbed(...).proj`，**与官方 `patch_embed` 是同一个 conv**
- `HoloAttention(use_nonlinear_v=False)` → `return super().forward(x)`，**就是官方 MDTA**
- `HoloGDFN(use_dirconv=False)` → `dirconv=Identity`，**就是官方 FeedForward**
- `HoloBlock` 开关全关时走快速路径，代码注释原文
  "*This branch deliberately mirrors TransformerBlock's two expressions*"：
  ```python
  x = x + self.attn(self.norm1(x))
  x = x + self.ffn(self.norm2(x))
  ```
- `HoloBandSplit` 只提供 `masks()` / `band_energy()` 两个方法，**在 forward 里没有任何调用点** —— 在基线版里是纯装饰，不参与计算

**重建头：现在有两种，用 `use_staged_head` 选**

```python
if use_staged_head:      # True（默认）：两级 3 通道像素重排
    self.output = nn.Conv2d(int(dim*2), out_channels, 3, 1, 1)          # 96 → 3
    self.reconstruction = SRUpsample(scale=4, channels=3)               # Conv(3,12)+PS2 → Conv(3,12)+PS2
else:                    # False：官方 Restormer SR 头
    self.output = nn.Conv2d(int(dim*2), out_channels * scale**2, 3,1,1)  # 96 → 48
    self.reconstruction = nn.PixelShuffle(scale)                        # PS4，无参数

# forward 两种都一样：
residual = self.reconstruction(self.output(dec1))
base = F.interpolate(inp_img, scale_factor=4, mode="bicubic")   # 官方本来就有这个全局残差
out = base + residual
```

参数量：**26,127,292**（`use_staged_head=True`）vs **26,165,524**（`False`，与 v6 那版完全一致），
差 38,232 全在重建头。

**当前状态（2026-10-13）**
- `holo_restormer_mdta_stockhead_60000_seed10_mb2`（**新，在跑**）：`use_staged_head: false`
  → **就是官方 Restormer SR**（26,165,524）。这就是论文里的 Restormer 基线。
- `holo_restormer_mdta_60000_seed10_mb2`（旧，跑到 ~36000 停）：`use_staged_head: true`（默认）
  → "Restormer + 两级重建头"的变体。**评估它必须显式传 `use_staged_head: true`**，否则权重不匹配。

## 3 所以论文的口径

| 想写的东西 | 能不能写 |
|---|---|
| "本文方法 = 条纹尺度 × 频带、带内复原/带外外推" | ❌ **现在不能**。这些模块在跑的网络里全是关的，写出来与实际模型不符 |
| "基线：官方 Restormer" | ✅ 成立 —— `..._stockhead_...` 这个 run 就是 26,165,524 的官方结构 |
| "基线：Restormer + 两级重建头（我们的变体）" | ✅ 也行，指旧的那个 run；但不能叫"官方 Restormer" |
| "HoloBandSplit 按物理截止频率分带" | ❌ 基线版里不参与计算；只有 `HoloRestormerV3` 打开 `use_restore_branch` 才会用 |

**两条出路，二选一：**
1. **改叙述** —— 论文只声称"Restormer 重建头改造 + 训练协议改进"，不声称频带/方向模块。
2. **跑真方法** —— 用 `network_g.type = HoloRestormerV3` 跑一次（默认全开），
   然后方法章节照它写。此时要同时报告开关清单与参数量/FLOPs。

## 4 `HoloRestormerV3` 打开后会多什么（开关名，供写方法章节）

| 开关 | 模块 | 作用 |
|---|---|---|
| `use_homomorphic` | `HoloStem` | 可学强度 Box-Cox 双域前端（`p` 可学，训练后应打印） |
| `use_restore_branch` | `FSASBranch` + `HoloBandSplit.masks` | 带内（pass+edge）复原支路 |
| `use_extrap_branch` | `FSASBranch` + `HoloBandSplit.masks` | 带外（stop）外推支路 |
| `use_dirconv` | `DirConv` | 方向性带通（`n_orient`，默认 6） |
| `use_multiscale` | `MultiScaleDW` | 多尺度深度卷积（散斑相关长度 3–6 px） |
| `use_nonlinear_v` | `HoloAttention` | value 通路加 tanh 非线性 |
| `use_skip_gate` | `BandGatedSkip` ×3 | skip 连接按带能量门控 |
| `use_unroll` / `unroll_K` | `HoloUnroll` + `HoloForwardDet` | HQS 物理一致性展开（**默认关**，且 K=1） |

`HoloForwardDet` / `HoloUnroll` 的实现已在源码里（含 Lanczos 降采样及其转置伴随），
**是否满足协议门槛 3（与 numpy 版 MSE < 1e-4、伴随性 atol 1e-3）尚未验证过**。
